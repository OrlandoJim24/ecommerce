# Nike Store UI

A responsive Nike store landing page built using **HTML, CSS, and JavaScript**.  
This project simulates a sneaker e-commerce interface with an interactive product slider, product details section, checkout modal, and responsive layout.

## Live Demo

https://nikeecommerce-eight.vercel.app

## Features

- Interactive sneaker product slider
- Product details section
- Checkout modal interface
- Responsive design for mobile devices
- Gallery section
- Seasonal promotion section
- Newsletter subscription section
- Social media footer

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

ecommerce/
├── index.html
├── styles.css
├── app.js
└── img/

## How to Run Locally

1. Clone the repository

git clone https://github.com/OrlandoJim24/ecommerce.git

2. Open the project folder

cd ecommerce

3. Open `index.html` in your browser.
